# Expériences

Un dossier par expérience, nommé `AAAA-MM-JJ-sujet/`, avec au minimum un `README.md` qui donne :

1. **La question** posée, et la piste de `pilotage/pistes/` dont elle vient.
2. **Les entrées** : la commande exacte qui télécharge les données (jamais les données elles-mêmes).
3. **La commande** lancée, avec le commit du code.
4. **Le résultat**, chiffré, y compris quand il est négatif.

Les sorties volumineuses (prédictions, poids) restent dans `data/` et `models/`, ignorés par git.
