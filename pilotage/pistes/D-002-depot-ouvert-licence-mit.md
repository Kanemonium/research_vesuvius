## Constat

Le règlement impose de publier sa méthode en open source, sous licence permissive, pour recevoir un prix. Il favorise les travaux publiés tôt, documentés et réellement utilisés.

## Réflexions

- **Kanemonium** (2026-11-14) : le projet doit « répondre à tous les critères d'open source », avec une CI vers GitHub, sur un compte dédié à la recherche.
- **Agent C.** (2026-11-14) : licence MIT, aucun secret ni aucune donnée dans le dépôt, et le carnet de recherche versionné avec le code pour que le raisonnement soit public lui aussi.
